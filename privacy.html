隐私政策

Coding Agent Communicator 浏览器扩展

1. 概述

Coding Agent Communicator（以下简称"本扩展"）是一个帮助用户标注网页元素、收集反馈信息的浏览器扩展。我们非常重视您的隐私，本政策旨在说明我们如何收集、使用和保护您的个人信息。

重要声明：本扩展的所有数据处理均在本地浏览器中进行，我们不会将任何数据发送到外部服务器。

2. 数据收集

2.1 我们收集的信息

  • 当前标签页信息：用于确定扩展在哪个标签页上运行
  • 页面元素信息：用户选择标注的网页元素的 CSS 选择器、位置坐标和尺寸
  • 用户输入的注释：用户为页面元素添加的文字反馈
  • 控制台错误：仅当用户选择时，捕获页面控制台的错误信息（用于调试参考）

2.2 我们不收集的信息

  • 不收集个人身份信息：我们不收集您的姓名、邮箱、电话等个人身份信息
  • 不收集浏览历史：我们不会记录或追踪您的浏览历史记录
  • 不收集页面内容：除非您手动选择标注，否则不会收集页面上的任何文字或图片内容
  • 不收集 cookies：我们不访问或存储任何 cookies

3. 数据使用

本扩展收集的所有数据仅用于以下目的：

  • 生成格式化的页面反馈报告
  • 在用户点击"完成并复制"时，将报告复制到剪贴板
  • 在页面会话期间临时显示标注标记

4. 数据存储

本扩展的所有数据均存储在本地浏览器中，以临时变量形式存在。当用户：

  • 关闭工具时，所有标注数据会被清除
  • 刷新页面时，所有标注数据会被清除
  • 点击"清空"按钮时，所有标注数据会被清除

我们不会在任何服务器上存储您的数据。

5. 权限说明

本扩展请求以下浏览器权限：

  • activeTab：允许扩展访问当前活动的标签页，用于在页面上添加标注功能
  • scripting：允许扩展在页面上注入脚本，用于实现标注功能
  • tabs：用于读取当前标签页的 URL，以便在输出报告中记录页面地址，并判断是否为系统页面（如 chrome:// 等不支持的页面）
  • clipboardWrite：用于将格式化后的反馈报告写入剪贴板，供用户粘贴发送给 Coding Agent

关于 iframe 支持

本扩展的内容脚本会注入到页面中所有的 iframe 框架（all_frames），这是为了支持在嵌套页面（如内嵌预览、组件库演示等 iframe 内的元素）上进行标注。脚本仅在用户主动启动工具后才执行元素高亮和标注功能，不会在后台持续读取或处理 iframe 内的页面内容。

6. 第三方服务

本扩展不使用任何第三方服务或 API。所有功能均在本地浏览器环境中运行。

7. 数据共享

我们不会与任何第三方共享您的数据。您通过"完成并复制"功能复制到剪贴板的内容完全由您控制如何使用。

8. 儿童隐私

本扩展不针对 13 岁以下儿童，也不会故意收集儿童的个人信息。

9. 政策更新

我们可能会不时更新本隐私政策。更新后的政策将在本页面发布，同时我们会在扩展描述中提示用户查看最新版本。
