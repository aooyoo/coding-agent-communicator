Coding Agent Communicator

向 Coding Agent 提供精准修改反馈的页面元素注释工具

安装扩展 试用演示 隐私政策

✨功能特点

🎨

可视化标注

鼠标悬停在页面元素上即可看到高亮效果，点击添加你的注释反馈

📍

精确定位

自动捕获元素的 CSS 选择器、位置坐标和尺寸信息

📋

一键导出

完成后点击"完成并复制"，结果自动格式化为 Markdown

🖼️

iframe 支持

支持在 iframe 内部元素上进行标注（同源 iframe 完全支持）

🐛

错误捕获

可选捕获控制台错误信息，帮助调试问题

🔒

隐私保护

所有数据处理均在本地进行，不会发送到任何服务器

🚀安装方法

1

下载扩展文件

从 GitHub 仓库下载最新的 release 压缩包或克隆代码

2

打开扩展管理页面

在浏览器地址栏输入 chrome://extensions 并按回车

3

启用开发者模式

点击右上角的"开发者模式"开关

4

加载扩展

点击"加载已解压的扩展程序"，选择下载的扩展文件夹

📝使用说明

1

启动工具

点击浏览器工具栏的插件图标，然后点击"启动工具"

2

添加注释

鼠标悬停在元素上，点击后输入你的反馈注释

3

导出结果

完成后点击"完成并复制"，结果会自动复制到剪贴板
